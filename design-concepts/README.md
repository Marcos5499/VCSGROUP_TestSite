# VCS Group: website design concepts

Three home-page directions for the VCS Group website, built as interactive artboards on a design canvas.

| File | Concept |
|------|---------|
| `Main.dc.html` | The brief, the brand palette (from the April 2025 company profile) and how to review the concepts |
| `OptionA-LagoonLight.dc.html` | **Lagoon Light**: clean and light in the style of Calendly, with a floating pill nav, division cards that expand on hover over a shared texture, and a click-through testimonial carousel |
| `OptionB-DeepOcean.dc.html` | **Deep Ocean**: immersive in the style of ER Group, with a full-screen overlay menu, the cover ribbon moving with the scroll, and division panels that stack on top of each other |
| `OptionC-HeritageHorizon.dc.html` | **Heritage & Horizon**: an editorial mix of the two, with serif display type, an interactive sector index, a bento grid, and a journey timeline that moves sideways as you scroll |

## Brand palette
- VCS Navy `#1D2A51` · VCS Teal `#3790AB` · Ribbon Blue `#3A85B5` · Group Silver `#A7A6A9`
- Supporting colours: Deep Navy `#141E3C` · Action Teal `#23748E` (buttons with white text) · Network Glow `#1F6FD1`

## Assets
`assets/` holds the VCS Group logo, extracted from the profile cover in light, dark and white versions, and the network image from the cover.
The `.dc.html` files point to these as uploaded canvas assets (`/_blob/...`).

Testimonials are placeholders: real client quotes still need to be supplied. Areas marked "Photo" are slots for VCS's own photography.
